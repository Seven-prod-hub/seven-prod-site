# Seven Prod

Site d'Ariel, photographe et vidéaste de mariage à Paris et en Île-de-France.

- `index.html` : page Mariage (accueil)
- `evenements.html` : fiançailles, henné, anniversaires
- `clips.html` : clips et shootings
- `mentions-legales.html` : à compléter (nom, adresse, SIRET) avant la mise en ligne

Site statique, sans dépendance : il suffit d'activer GitHub Pages sur la branche `main` le jour de la mise en ligne.
